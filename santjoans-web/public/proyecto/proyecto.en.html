SANTJOANS Project Information

Note on dates: This is a 2010–2011 project. The study of the floor, the photography of the tiles and the development of the web application were carried out between 2010 and 2011, and presented publicly in August 2010. In 2026, only a technological update of the web application was carried out —with no changes to the content or images— to ensure its long-term operation. The rest of this document reflects the original project. See the section 2026 Rewrite for details of that update.

The Santjoans Palace, and above all its fantastic collection of Zoo-Morphic ceramics, are among the finest elements of the heritage of Cinctorres.

This project was initiated with the aim of making it easier to enjoy this collection while also preserving it digitally and documentally. We also trust that it will help promote Cinctorres and provide further arguments for the long-overdue restoration of the Palau Santjoans to finally go ahead.

Please note that this website is designed to facilitate the visual enjoyment of the tiles, and that parallel material providing the results of the research is also available.

Tile digitisation

Initially, the central tiles and the fill tiles have been incorporated (the fill tiles are a repetition of the same design at different rotation angles around the perimeter).

Each tile is photographed and incorporated at several sizes, so that each zoom level can, if desired, be assigned a different image size. Without going into detail, the aim is a compromise solution so that the system can be used on both high-speed and low-speed internet connections, and there are six zoom levels.

Fidelity of representation

After the initial study of the project we concluded that the floor design was composed of four zones.
  1. Central shield: It consists of the shield, made up of 12 tiles (4 × 3), surrounded by a border of marble-effect tiles, which in turn is surrounded by another border of flower tiles. At the top and bottom (according to the angle required to view the shield correctly) a row of zoo-morphic tiles is added.
  2. Zoo-morphic tiles: A total of 326 zoo-morphic tiles surround the central shield, arranged diagonally at 45° (those inside the shield are not counted). This diagonal arrangement means that at the junction with the central shield there are half-tiles, which were made using flower tiles.
  3. Fill tiles: From an aerial view, the whole arrangement is surrounded by a frame of square bisque tiles (two tiles wide). All the space between the zoo-morphic tiles and the bisque frame is filled with flower tiles in the same 45° diagonal arrangement as the zoo-morphic tiles.
  4. Frame: As already noted, these are the bisque tiles that surround the entire floor, placed normally (not diagonally) around all the other tiles.
In addition to this general classification, there are some particular features:
  1. On the two long sides of the marble-effect tile border surrounding the shield, there are two tiles cut to approximately a sixth of their full width (like a very narrow border strip) that help the surrounding tiles fit neatly around their content.
  2. At the four corners there is a square made up of four tiles (2×2) of the marble-effect type found around the shield.
  3. In one corner, a few fill tiles with a different flower design were used — as if the original tiles ran out and different material had to be used.
The hall where the tiles are laid is trapezoidal rather than rectangular, so we believe the laying was carried out as follows:
  1. First, the shield and its decorative elements (marble border, flower border, top and bottom rows) were placed where the centre was calculated to be.
  2. The zoo-morphic tiles were then laid diagonally around the shield (with more layers on the long side of the room than on the narrow side). You can see how on the side nearest the entrance door, tiles were missing, since the usual pattern is broken.
  3. Around the zoo-morphic tiles, continuing the diagonal pattern, the fill tiles (those with the flower motif) were placed, working towards the walls until the space for the two bisque tiles remained.
  4. The bisque tiles were then placed in the remaining space between the wall and the outermost fill tiles.
Because the room is trapezoidal rather than rectangular, reproducing the exact layout of all the tiles introduces a very high level of complexity. For this reason it was decided that the goal was the faithful reproduction of the central shield and the zoo-morphic tiles, while the fill tiles would be adapted to the constraints of the software.
This means that the fill completes the space between the zoo-morphic tiles and a perfect rectangular room.
The bisque tile frame is of no particular interest and is not reproduced.

The design that has been represented, along with the coordinate system used, can be seen in this virtual model diagram. We can also see the diagram corresponding to the real model and another showing both models superimposed.

In these diagrams (especially the superimposed one) it can be seen how the area bounded by the red outline, corresponding to the shield, and the area bounded by the yellow outline, corresponding to the zoo-morphic figures, is identical in the virtual and real models.

Project history

2010 — Start and public presentation. The project began with the photographic and documentary study of the floor. On 11 August 2010 it was presented publicly at the Antic Escorxador de Cinctorres, as part of the Agost Cultural 2010 programme. Both Francisca Julian's academic study and the first prototype of the web application were shown.

January–March 2011 — Development and launch. The web application was published in January 2011 with an initial set of digitised tiles. During the following weeks the remaining tiles were added in nine successive versions (v1–v9). In version 4 the Creative Commons BY-NC licence was defined for the images. On 24 March 2011, with more than 400 zoo-morphic tiles represented, the project was declared complete.

May 2011 — Internet Explorer 9 compatibility. Support for IE9 was added, achieving performance comparable to Google Chrome at that time.

July 2011 — Own domain. The website was migrated to its own server under the domain santjoans.es, improving loading speed and project identity.

November 2011 — Source code published. The source code of the original application (in GWT) was published in an SVN repository, and subsequently migrated to Git at github.com/jtpadilla/santjoans.

2026 — Technology update. With no changes to the content or images, the application was rewritten using modern technology to ensure its long-term operation. See the following section for more details.

2026 Rewrite with Claude Code

In 2026 the application was completely rewritten from scratch using modern technology.

Motivation. The original version (2011) was built on GWT (Google Web Toolkit), a framework that compiles Java to JavaScript. GWT was discontinued in 2020 and its ecosystem of auxiliary libraries (google-web-toolkit-incubator, gwt-image-loader) has been unmaintained for years. Furthermore, the original application required a Java server (Tomcat/Jetty) to be served, which made deployment and long-term maintenance difficult.

New stack. The rewrite uses exclusively standard web technology: React 19 + TypeScript as the UI layer, Vite as the build tool, Zustand for interface state, and Vitest for unit tests of the mosaic geometry. The tile catalogue (originally in XML) is converted to JSON at build time using a Vite plugin, eliminating any server-side processing. The result is a bundle of approximately 70 KB (compressed) served as a completely static site.

Fidelity. The render engine is still Canvas 2D, reproducing the same millimetre coordinate system that GWT used internally. The hit-testing algorithm (detecting which tile is touched on double-click or tap) was ported function by function from the original Java, including the integer truncation of divisions that is critical for precision. The visual and interaction behaviour —zoom, pan, tile popup, minimap, drag— is identical to the original.

New features compared to the original. The new version adds capabilities that 2011 technology did not allow: full touch support (single-finger drag, two-finger pinch-to-zoom, tap to open a tile popup), responsive design that adjusts the canvas size to the viewport and reacts to device orientation changes, and a coherent visual redesign with modern typography and a colour palette inspired by Mediterranean ceramics. The interface is also available in Spanish, Catalan, English and Chinese.

Process. The migration was carried out using Claude Code (Anthropic's AI-assisted programming tool from Anthropic). Claude Code analysed the original Java code, designed the equivalent TypeScript architecture and generated the code for each module in five phases: project scaffolding, data model and geometry, canvas engine and UI components, visual verification and integration, and CSS adjustments and cross-browser compatibility. The source code for the new version is available in the same repository: github.com/jtpadilla/santjoans (folder santjoans-web/).
