SANTJOANS 项目信息

关于日期的说明：这是一个 2010—2011 年的项目。地面瓷砖的研究、瓷砖的拍摄和网页应用的开发都在 2010 至 2011 年间完成，并于 2010 年 8 月公开发布。2026 年只对网页应用做了一次技术更新——内容和图片均未改动——以保证它能长期运行。本文档的其余部分反映的是最初的项目。关于这次更新的详情，请参阅2026 年重写一节。

Santjoans 宫，尤其是其中精美的动物纹样瓷砖收藏，是 Cinctorres 最珍贵的文化遗产之一。

本项目的初衷是让更多人能够欣赏这批藏品，同时以数字和文献的形式将其保存下来。我们也希望它有助于宣传 Cinctorres，并为最终推动 Santjoans 宫的修复提供更多理由。

需要说明的是，本网站的目的是方便大家欣赏这些瓷砖；研究所得的数据另有配套材料提供。

初次使用

进入本站后，首先看到的是一个带有简短说明的欢迎页面。说明中配有一些图片，用鼠标点击即可放大。说明中嵌入的链接可以打开其他图片和补充说明。
在阅读说明的同时，组成地面的瓷砖图片会在后台加载；全部加载完成后，会出现一个进入地面浏览器的按钮。

点击查看地面按钮即可进入地面浏览器。

瓷砖的数字化

最初纳入的是中央区域的瓷砖和填充瓷砖（后者在整个外围重复同一图案，只是旋转角度不同）。

每块瓷砖都经过拍摄，并以多种尺寸存入系统，因此每个缩放级别都可以按需指定与其他级别不同的图片尺寸。简单地说，我们寻求的是一种折中方案，使系统在高速和低速网络连接下都能使用；缩放共有六个级别。

再现的忠实程度

经过对项目的初步研究，我们得出结论：地面的设计由四个区域组成。
  1. 中央盾徽：盾徽本身由 12 块瓷砖（4 × 3）组成，外围先是一圈仿大理石纹样的瓷砖，再外一圈是花卉纹样的瓷砖，最后在上端和下端（按照正确观看盾徽的角度而定）各铺一行动物纹样的瓷砖。
  2. 动物纹样瓷砖：共 326 块动物纹样瓷砖环绕中央盾徽，呈斜向（菱形）铺设（盾徽内部的不计在内）。由于斜向铺设，在与中央盾徽衔接处会出现半块砖，这些位置用花卉纹样的瓷砖填补。
  3. 填充瓷砖：如果从空中俯视，会看到整个地面被一圈方形素烧砖（两块砖宽）构成的边框围住。动物纹样瓷砖与素烧砖边框之间的全部空间，都用花卉纹样的瓷砖填满，铺设方向与动物纹样瓷砖相同，也是斜向的。
  4. 边框：如上所述，就是环绕整个地面的素烧砖，它们采用正常铺法（不斜向），围在其余瓷砖的外侧。
除了这种总体分类之外，还有一些特殊之处：
  1. 在围绕盾徽的仿大理石砖框的两条长边上，各有两块被切成约六分之一的窄砖（好像一条很细的饰带），用来让周围的瓷砖恰当地贴合其内部的内容。
  2. 在四个角落各有一个由四块砖（2 × 2）组成的正方形，砖面仿大理石纹样，与围绕盾徽的那种相同。
  3. 在一个角落里，使用了少量花卉图案与常规不同的填充砖。看上去像是砖不够用了，于是用了其他材料。
铺有瓷砖的大厅并非矩形，而是梯形，因此我们认为铺设是按以下顺序进行的：
  1. 先在估算出的中心位置铺设盾徽及其装饰元素（大理石纹砖框、花卉砖框、上端和下端）。
  2. 然后围绕盾徽斜向铺设动物纹样瓷砖（在餐厅较长的一侧铺的层数多于较宽的一侧）。可以看到，在通向入口门的那一侧瓷砖不够，因为常规的铺设规律在那里中断了。
  3. 接着在动物纹样瓷砖外围继续斜向铺设填充砖（即带一朵花图案的瓷砖），尽量靠近墙壁，只留出两块素烧砖的空间。
  4. 最后在墙壁与最外层填充砖之间的空间铺上素烧砖，完成整个地面。
由于房间是梯形而非矩形，要精确再现每一块瓷砖的位置会带来极高的复杂度。因此我们确定的目标是忠实再现中央盾徽和动物纹样瓷砖，而填充瓷砖则根据软件的限制作出调整。
也就是说，填充砖所填补的是动物纹样瓷砖与一个理想矩形大厅之间的空间。
素烧砖边框没有欣赏价值，不予再现。

项目历程

2010 年——启动与公开发布。 项目从地面瓷砖的摄影和文献研究开始。2010 年 8 月 11 日，在 Cinctorres 旧屠宰场（Antic Escorxador）、 2010 年文化八月活动期间，公开发布了 Francisca Julian 的学术研究和网页应用的第一个原型。

2011 年 1—3 月——开发与上线。 网页应用于 2011 年 1 月上线，首批包含一部分数字化的瓷砖。随后几周里，其余瓷砖通过九个连续版本（v1—v9）陆续加入。第 4 版确定了图片采用知识共享 BY-NC 许可协议。 2011 年 3 月 24 日，在呈现了 400 多块动物纹样瓷砖之后，项目宣告完成。

2011 年 5 月——兼容 Internet Explorer 9。 加入了对 IE9 的支持，性能达到了与当时的 Google Chrome 相当的水平。

2011 年 7 月——独立域名。 网站迁移到自己的服务器，使用域名 santjoans.es，提高了加载速度，也更便于识别项目。

2011 年 11 月——公开源代码。 原始应用（GWT）的源代码发布在一个 SVN 仓库中，后来迁移到 Git，地址为 github.com/jtpadilla/santjoans。

2026 年——技术更新。 在内容和图片均不改动的前提下，应用以现代技术重写，以保证其长期运行。详见下一节。

2026 年用 Claude Code 重写

2026 年，应用以现代技术从零开始完全重写。

动机。原版（2011 年）基于 GWT（Google Web Toolkit）构建，这是一个把 Java 编译为 JavaScript 的框架。GWT 已于 2020 年停止开发，其配套库生态（google-web-toolkit-incubator、gwt-image-loader）多年无人维护。此外，原版应用需要一台 Java 服务器（Tomcat/Jetty）才能运行，这给部署和长期维护带来了困难。

新技术栈。重写完全采用标准 Web 技术：React 19 + TypeScript 作为界面层，Vite 作为构建工具，Zustand 管理界面状态，Vitest 用于马赛克几何计算的单元测试。瓷砖目录（原为 XML）在构建时通过一个 Vite 插件转换为 JSON，从而免去了任何服务器端处理。最终产物是一个约 70 KB（压缩后）的包，以纯静态网站的形式提供。

忠实性。渲染引擎仍然是 Canvas 2D，沿用了 GWT 内部所使用的同一套毫米坐标系统。命中检测算法（判断双击或点按时触碰的是哪块瓷砖）从原始 Java 代码逐个函数移植而来，包括对精度至关重要的整数除法截断。视觉和交互行为——缩放、平移、瓷砖弹窗、小地图、拖动——与原版完全一致。

相对于原版的新功能。新版本加入了 2011 年的技术无法实现的功能：完整的触控支持（单指拖动、双指捏合缩放、点按打开瓷砖弹窗），自适应（responsive）设计，画布尺寸随视口调整并响应设备方向的变化，以及一次统一的视觉重设计，采用现代字体和取材于地中海陶瓷的配色。此外，界面提供西班牙语、加泰罗尼亚语、英语和中文版本。

过程。迁移工作使用 Claude Code （Anthropic 的 AI 辅助编程工具）完成。 Claude Code 分析了原始 Java 代码，设计了等价的 TypeScript 架构，并分五个阶段生成各模块的代码：项目脚手架，数据模型与几何计算，Canvas 引擎与界面组件，视觉验证与集成，以及 CSS 调整与跨浏览器兼容。新版本的源代码在同一仓库中：github.com/jtpadilla/santjoans （santjoans-web/ 目录）。
